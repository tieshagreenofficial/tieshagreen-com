# tieshagreen-com

Production source for tieshagreen.com, Tiesha Green's main hub homepage. Renamed Aug 14, 2026 from `the-business-of-greatness-site`, the old name and description were leftover from before and caused a real mix-up with a different, unrelated site. Connected to the Vercel project `tiesha-green-website`, which owns the tieshagreen.com domain. Every push to `main` redeploys automatically.

Static site: `index.html` + `style.css` + `script.js`, plus `privacy.html` and `terms.html`.
