# the-business-of-greatness-site

This is the actual production source for tieshagreen.com (confirmed Aug 14, 2026: byte-identical to the live site). The repo name and old description are misleading, this is NOT a separate Business of Greatness / Wealthy Expert site, it's Tiesha Green's main hub homepage. Connected to the Vercel project `tiesha-green-website`, which owns the tieshagreen.com domain. Every push to `main` redeploys automatically.

Static site: `index.html` + `style.css` + `script.js`, plus `privacy.html` and `terms.html`.
